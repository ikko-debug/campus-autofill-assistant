# 秋招本地填表助手

一个纯本地 Chrome Manifest V3 扩展，用于辅助填写常见校招与社招表单。

## 安装

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `campus-autofill`。
5. 固定扩展图标，先进入“编辑本地资料”补全身份证号、紧急联系人、期望城市等信息。

## 使用

1. 打开招聘网站的简历编辑页面，并先在网页中展开或新增所需经历卡片。
2. 点击扩展图标，确认识别到正确网站。
3. 默认仅填写网页中的空字段；如确需更新已有内容，再勾选“覆盖网页已有内容”。
4. 点击“填写当前页面”。
5. 逐项检查下拉框、日期、地区、文件和必填项，最后由本人手工提交。

## 隐私与安全

- 资料仅保存在 `chrome.storage.local`。
- 不使用远程服务、AI API、分析统计或云同步。
- 不自动上传简历、照片或附件。
- 不读取密码、验证码，也不自动点击最终提交按钮。
- 身份证号等简历未提供的信息默认为空，由本人在设置页补充。
- 公开版默认资料为空；请勿把填写过真实个人资料的 JSON 或扩展目录上传到公开仓库。

## 当前适配范围

- Moka、腾讯：使用站点专用适配。
- 北森 Beisen：根据 Phoenix 组件和页面特征自动识别，不依赖公司域名；工作、实习、教育、项目等字段按标签和区块尝试匹配。
- 飞书 ATS：根据 `atsx-*` 组件自动识别，不依赖具体招聘域名。
- 其他招聘表单：通用适配器根据中英文标签、占位文字和字段名识别实习/工作经历及项目经历。
- 经历匹配优先使用公司名或项目名，不依赖资料与网页卡片的排列顺序；空白卡片再按资料顺序填充。
- 日期选择器、地区级联、多选城市、附件上传和新增/删除重复区块仍保留手工确认。

通用适配器只处理已经渲染的经历卡片。标签完全自定义、字段藏在 iframe/Shadow DOM 中，或页面未展开经历区块时，需要手工处理或增加站点专用适配。

## 本地验证

macOS 安装 Chrome 后可运行：

```sh
./tests/run-fixtures.sh
```

测试覆盖腾讯、飞书与通用表单，并验证网页卡片顺序与资料顺序不一致时仍能按公司名、项目名匹配。

## 参考

实现思路参考了 MIT 协议项目 JobMatchAI 的原生 value setter、事件模拟与严格字段匹配方式，以及 Offer Laolao 的中文资料结构和点选填充设计。此扩展代码为针对 Moka 与腾讯校招重新实现的独立版本。
